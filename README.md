# Parking Slot Manager

## Problem Statement

Managing parking manually can make it difficult to track available slots, parked vehicles, entry/exit times, and parking charges.

The **Parking Management System** provides a simple digital solution to manage parking slots, register vehicles, track parking records, calculate fees, and maintain parking history.


## Objectives

* Manage parking slots
* Register vehicles
* Track vehicle entry and exit
* Calculate parking fees
* Maintain parking records
* Validate user input

## Planned Features

* Vehicle registration
* Parking slot management
* Vehicle entry and exit
* Parking slot assignment
* Parking fee calculation
* Parking history
* CRUD operations
* Input validation
* Relational database storage
* Simple user interface
